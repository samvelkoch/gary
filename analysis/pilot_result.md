# Пилот разметки иронии — результат (2026-09-30)

Правило (записано в `pilot.py` до разметки): каппа Коэна «ирония есть / нет» на 80 фрагментах,
«не уверен» = «нет»; ≥ 0,6 — разметка модели пригодна, пилот расширяется; < 0,6 — не публикуем.

| | Значение |
|---|---|
| Каппа (80 фрагментов) | **0,42** — ниже порога, пилот не пройден |
| Совпадение | 70% |
| Доля «ирония есть»: заказчик / модель | 46% / 71% |
| Расхождения «модель да, заказчик нет» | 20 из 24 |
| «Пляска Чингиз-Хаима» | каппа 0,66 (злой сарказм с явной мишенью видят оба) |
| «Обещание на рассвете» | каппа 0,23 (мягкий юмор о матери модель считает иронией) |
| «Вся жизнь впереди» | каппа 0,33 (наивный голос Момо модель считает иронией) |

Разведка, не засчитывается (подгонка на тех же данных): если считать иронией только типы модели
«сарказм» — каппа 0,43; «сарказм + антифразис» — 0,46; всё, кроме самоиронии и снижения — 0,50.

Маркеры (markers.py): среди фрагментов с «ироническими кавычками» или «притворной уверенностью» модель
видит иронию в 78% случаев, среди случайных без маркеров — в 66%; «столкновение высокого и низкого» почти
не встречается в абзацах 25–160 слов. Маркеры — слабое сито, не мера.

Цитаты заказчика (@matautu, 2011–2015): 230 цитат, 187 найдены в корпусе (81%).
